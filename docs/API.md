# Local engine API contract v1

Engine: Python standard library HTTP server launched with `python3 engine/server.py --state-dir PATH`. Bind 127.0.0.1 ephemeral port; private state directory and endpoint.json mode 0600. endpoint.json = {"url":"http://127.0.0.1:PORT","token":"random-secret"}. Authenticate all requests with Bearer token. Reject browser Origin and unexpected Host. Local SQLite single owner lock. Jobs outlive GUI; UI may close only after requesting safe pause or electing background work. Do not terminate backend on ordinary GUI closure.

All fields snake_case, all replies JSON. Errors {"error":"actionable message"} with non-200 code. GET /status -> {"settings":Settings,"jobs":[Job],"discs":[Disc],"tools":{"makemkv":string|null,"ffmpeg":string|null,"ffprobe":string|null},"safe_to_disconnect":bool,"message":string}. GET /jobs/ID -> Job. GET /report/ID -> compact verification report. POST /scan {} -> {"discs":[Disc]}. Scan only; never starts extraction. GET /settings -> Settings. POST /settings Settings -> Settings. POST /jobs {"source_path":string,"disc_id":optional string,"collection":string,"kind":"film"|"series"|"extras","titles":[{"id":int,"name":string}],"stop_after":"scan"|"acquire"|"encode"|"verify"|"complete"} -> Job; select known scan results or a local media file. POST /jobs/ID/action {"action":"resume"|"pause_after_checkpoint"|"next_checkpoint"|"cancel","stop_after":optional string} -> Job. POST /profiles {"disc_id":string,"collection":string,"kind":string,"titles":[{"id":int,"name":string}]} -> profile. GET /profiles -> {"profiles":[...]}. POST /shutdown {} -> accepted ONLY when no job active.

Settings: {"output_root":string,"auto_start":bool,"video_codec":"hevc"|"h264","quality":int,"languages":[string]}. Defaults output_root empty until chosen, auto_start false, hevc, quality 18, [eng,deu]. Profiles must be exact structural disc IDs; unknown discs stay needs_identification. Automatic scan polling backend or UI; only known saved profiles automatically start when enabled. Disc {"id":string,"label":string,"format":string,"source_path":string,"drive_index":int|null,"identified":bool,"collection":string|null,"titles":[{"id":int,"name":string,"duration":string,"size":string}],"message":string}. For local media source one title id 0.

Job {"id":string,"collection":string,"kind":string,"state":string,"phase":string,"checkpoint":string,"stop_after":string,"source_path":string,"output_path":string,"progress":number 0..1,"message":string,"safe_to_disconnect":bool,"titles":[{"id":int,"name":string}],"created_at":string,"updated_at":string}. States queued/running/paused/blocked/completed/cancelled/failed. Phase scan/acquire/encode/verify/complete. checkpoint denotes last committed phase. Active phase claims no physical or perceptual TV acceptance. Retain originals/subtitles and expose pending acceptance in reports. Source mounting identity & hash preflight; destination volume UUID/mount identity prevents recreating missing /Volumes paths. Never expose token in status/reports/logs.

Additive progress fields: phase_progress number|null, current_title string|null, processed_bytes integer|null, total_bytes integer|null, completed_items integer, total_items integer, elapsed_seconds number, throughput_bps number|null, eta_seconds number|null, last_progress_at UTC|null, heartbeat_at UTC, stall_reason string|null, next_checkpoint string, pause_requested bool, progress_basis string. Overall progress counts committed checkpoints. Phase progress resets per tool/title operation and is measured from tool events. Bytes are output bytes when known. ETA is an estimate for the active tool operation. Engine heartbeat is separate from advancing media. Unknown totals stay null.

Disc optionally includes kind from its saved profile. Every scanned title includes selected bool and restores its mapped name if selected. Manual scans never initiate acquisition. Background mount polling may start exact saved profiles with auto_start enabled. Cancellation finishes the current phase before becoming terminal, retaining artifacts.
