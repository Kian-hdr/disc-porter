# Disc Porter 0.2 shared implementation contract

Keep v1 routes operational and existing public Job/Disc fields. Add schema/API version 2 and engine_version=0.2.0. All requests authenticated as before, JSON snake_case. Settings, presets, profiles and jobs carry revision integers. Mutations may include expected_revision; stale revisions return HTTP 409 with error/code/current_revision. Revisionless legacy calls remain supported for v1 fields only. New clients always supply revisions. Idempotency_key on POST /jobs is stored with normalized request fingerprint; identical repeats return same job, conflicting payload rejects. Long media inspection/hashing must not hold control-plane mutex.

Settings retains output_root/auto_start/video_codec/quality/languages. Add fields below; GET returns all, PATCH /settings merges requested fields with expected_revision. UI and MCP use capability field schemas to validate supported values. Presets contain id,name,builtin,revision,settings (recipe fields); immutable builtins balanced/compatibility/original/legacy, duplicate via POST /presets {name,base_id}, update via PATCH /presets/ID {expected_revision,settings,name}, remove custom via DELETE /presets/ID. GET /presets -> {presets:[...]}. Settings preset_id chooses default. POST /settings remains legacy adapter.

Defaults for fresh settings: schema_version=2, revision=1, preset_id=balanced, mode=transcode, video_codec=hevc, quality=20, languages=[] (all source languages), output_container=mp4, encoder=software, speed=medium, bitrate_kbps=0, bit_depth=source, resolution=source, frame_rate=source, deinterlace=auto, aspect=preserve; output_root='', work_root='', original_root='', folder_layout=organized, file_template='{title}', reserve_bytes=1000000000; audio_policy=main_per_language, audio_codec=aac, audio_bitrate_kbps=384, audio_channels=source, include_commentary=false, default_audio_language='', preserve_original_audio=true; subtitle_policy=text, subtitle_languages=[], default_subtitle_language='', preserve_bitmap_subtitles=true; auto_start=false, default_checkpoint=complete, on_battery=pause, auto_resume=true, retry_count=2, max_encoders=1, cleanup_policy=keep (other enum delete_verified), notifications=true, online_lookup=false, appearance=system; ffmpeg_path='',ffprobe_path='',makemkv_path=''. Migration maps v1 saved values to legacy preset, preserves paths/settings/job snapshots, and keeps cleanup_policy=keep. Original mode completes acquire/verify/promote of originals, no lossy encoding or original cleanup.

Allowed controls: output_container mp4/mkv; encoder software/hardware; mode transcode/original; speed encoder-supported values; bit_depth source/8/10; resolution source/480p/720p/1080p/2160p; frame_rate source/24/25/30/50/60; deinterlace auto/off/frame/field; aspect preserve/square; audio_policy main_per_language/all/selected; audio_codec aac/ac3/copy; audio_channels source/stereo; subtitle_policy text/copy/burn/none; folder_layout organized/flat; on_battery pause/run. titles accept audio_streams:[int],subtitle_streams:[int],overrides:recipe patch, season:int,episode:int,year:int where applicable. Unknown language tracks can remain und; never invent tags. Invalid/unsupported combinations reject with reason and correction. HDR/Dolby Vision transcode blocked; original mode supported. Hardware requires explicit target bitrate. Downconversion is an explicit recipe setting, recorded in transform and validated. Originals, alternate audio and bitmap subtitles remain available or preserved in verified .mka/.mks sidecars before allowed cleanup.

Verify copy hash, atomic no overwrite. Hardlink optimization with verified copy fallback.

UI/MCP parity applies app operations only, no arbitrary shell/OS permissions.

Bundled helper entry engine/helper.py subcommands serve --state-dir PATH, supervise PARENT_PID -- TOOL ARGS, mcp. PyInstaller one-folder includes engine and bridge dependencies. Packaging owner exposes bundle Contents/Helpers/DiscPorterHelper/disc-porter-helper; engine supervisor must use helper dispatch when frozen, never sys.executable runner.py then. ## Final interface clarifications

- POST /jobs/preview returns plan_fingerprint; POST /jobs accepts expected_plan_fingerprint. This binds the accepted recipe and independent preset/profile revisions, checked both before expensive work and at commit. UI always sends it. Idempotency keys remain stable across retries of the same accepted plan.
- POST /jobs and PATCH /jobs/ID accept confirm_transforms. A source 10→8 bit conversion requires explicit confirmation or a direct bit_depth override; choosing Compatibility alone is insufficient.
- Title selection supports default_audio_stream, default_subtitle_stream and forced_subtitle_streams. Missing forced list preserves source flags; an explicit empty list clears them. Default audio follows source order/default unless language priority is supplied.
- cpu_threads=0 is automatic; explicit values are capped by actual CPU count. One encoder is supported and exposed honestly as a capability limit.
- delete_verified requires original-audio and bitmap-subtitle preservation. Incompatible recipes fail preflight; Keep permits omitting optional sidecars while retaining the original. Cleanup protects current and archived original references held by other jobs.
- Reports distinguish technical verification from supplied manual acceptance. MP4 single-subtitle default metadata is adjusted before full decode/hash publication; current Mac AVPlayer fixture verified selectability and cue delivery, not physical-TV acceptance.
- Native notification permission is requested only by an explicit in-app button. Delivery requires the native app process and OS authorization. Closing a window keeps observation alive; explicit Quit leaves only engine audit/history for the next launch.
- MCP exposes 43 typed tools. V2 mutations check engine/API compatibility before delivery; legacy tools remain compatible where no v2 settings are involved. The app-contained helper starts/reconnects the engine without needing the GUI.
